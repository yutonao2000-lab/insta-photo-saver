# Insta Photo Saver

iPhone向けの広告なし静的PWA。画像を端末から複数選択し、iOS共有メニューに渡します。InstagramのURLから投稿画像を自動取得する機能はありません。

## GitHub Pages公開

リポジトリのルートに全ファイルとiconsフォルダをアップロードし、Settings → Pages → Deploy from a branch → main / (root) → Save を選択します。数分後に公開URLをSafariで開き、共有 → ホーム画面に追加を選択します。

## 注意

画像はページを再読み込みすると一覧から消えます。画像自体はサーバーへ送信されません。共有画面を閉じたことと写真アプリへの保存成功は同義ではありません。
